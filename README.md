# 🎯 Quizzes Website

An interactive multi-subject quiz website built using **HTML, CSS, and JavaScript**. The platform allows users to take quizzes on different programming and computer-related subjects, answer multiple-choice questions, and view their final score.

## 🌐 Live Demo

https://quizzes-website.vercel.app/

## 📂 GitHub Repository

## ✨ Features

* 🔐 User Login

## 🚀 How to Run

### Clone the Repository

```bash
git clone https://github.com/kishor0917/quizzes-website.git
```

### Open the Project

```bash
cd quizzes-website
```

Then open `index.html` in your browser.

You can also use **VS Code Live Server** to run the project.

## 🎮 How It Works

1. Open the website.
2. Login to the platform.
3. Select a subject.
4. Answer the multiple-choice questions.
5. Submit the quiz.
6. The JavaScript calculates the score.
7. View the final result.
8. Complete the quiz through the Thank You page.
